# NiceSnooker 🎱

A lightweight snooker technology software simulator for physics modeling, trajectory prediction, and shot analysis.

## ✨ Features

- **Physics Simulation** — Rigid-body collisions, cushion rebounds, and spin (screw, follow, side).
- **Trajectory Modeling** — Cue ball paths, aiming lines, and multi-cushion angles.
- **Shot Analytics** — Break-building analysis and positional play simulation.

## 🚀 Getting Started

```bash
git clone https://github.com/shanpaocnm/nicesnooker.git
cd nicesnooker
```
